# School Widget 배포

학교 컴퓨터용 바탕화면 위젯(시간표·캘린더·급식·날씨 등)의 설치 파일을 올려 두는 곳입니다.
코드는 다른(비공개) 저장소에서 관리하고, 이 저장소에는 완성된 설치 파일만 올라옵니다.

## 설치

1. [최신 버전 받기](https://github.com/VioletWizard-lim/school-widget-releases/releases/latest)에서
   `SchoolWidget-Setup-버전.exe`를 내려받습니다.
2. 내려받은 파일을 실행하면 바로 설치되고 위젯이 켜집니다. 관리자 권한은 필요 없습니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요(서명되지 않은 프로그램이라 뜨는 안내입니다).
3. 위젯의 설정(⚙)에서 학교·학급을 등록하고, 원하면 **Windows 시작 시 자동 실행**을 켭니다.

## 업데이트

따로 할 일이 없습니다. 위젯이 새 버전을 확인해 백그라운드로 받아 두었다가,
다음에 켤 때(또는 트레이 아이콘 메뉴의 **업데이트 설치하고 다시 시작**을 누르면) 자동으로 설치합니다.

## 예전 portable 버전(SchoolWidget-portable.exe)을 쓰던 경우

1. 실행 중인 위젯을 트레이 아이콘 메뉴에서 **종료**합니다.
2. 위의 설치 방법대로 새 설치 파일을 한 번 실행합니다. 설정·일정은 그대로 유지되고,
   자동 실행도 새로 설치된 위치로 알아서 바뀝니다.
3. 예전 `SchoolWidget-portable.exe` 파일은 지워도 됩니다.
